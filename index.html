OPTREE CORE

Optree Framework

Optree Framework는 Optimize3D가 독자적으로 개발한 Octree 기반 산업용 포인트클라우드 구조입니다. 초대용량 데이터를 공간 영역과 LOD 단계로 계층화하고 필요한 영역과 상세도만 점진적으로 불러옵니다. 주요 LOD 구조는 MultiViewer에 구현·적용되어 여러 대규모 스캔을 효율적으로 검토하며, 경량 표시 데이터와 원본 포인트의 연결도 유지합니다.
