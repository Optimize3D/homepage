PROPRIETARY OPTREE ENGINE

전체를 먼저.
필요한 곳은 더 자세하게.

Optree는 수십 기가바이트 규모의 포인트클라우드를 경량 가시화하고, 웹 기반으로 스트리밍하는 자체 핵심 엔진입니다. 공간과 상세 단계로 데이터를 나누어, 현재 화면에 필요한 3D 데이터부터 점진적으로 전달합니다.

VIEW-ADAPTIVE DETAIL

화면에 필요한 상세도만 선택합니다.

LOD(Level of Detail)는 화면에 맞춰 데이터의 상세도를 고르는 기술입니다. 전체 형상을 먼저 표시하고, 확대하거나 시점을 옮기면 필요한 영역의 점 데이터를 추가합니다.

  • 공간 영역과 상세 단계를 구분하는 계층 구조
  • 화면에 보이는 영역·확대 수준·가용 자원을 고려한 데이터 선택

WEB-BASED ACCESS

PC부터 모바일까지, 웹으로 쉽게 접근합니다.

Optree 기반 스트리밍 서버가 대용량 점군을 계층형 LOD로 관리하고, 화면에 필요한 데이터를 점진적으로 제공합니다. 사용자는 PC·스마트폰·태블릿의 웹 브라우저에서 접속해 전체 형상부터 관심 영역까지 쉽게 살펴볼 수 있습니다.

  • 기기별 화면과 가용 자원에 맞춘 경량 스트리밍
  • 전체 원본 파일을 내려받지 않고 웹으로 점군 탐색

이미지는 기술 이해를 위한 AI 생성 개념 이미지입니다.

기술 구성 살펴보기 ＋

서버는 원본과 계층 데이터를 관리합니다.

E57·PLY 등 원본 점군을 읽어 공간 계층과 표시용 데이터를 준비합니다. 클라이언트는 공통 LOD 노드 규격으로 필요한 영역을 요청하며, 원본 관리와 데이터 준비는 서버에서 수행합니다.

시점과 자원에 맞춰 전송을 조절합니다.

카메라 방향과 화면에 투영되는 크기, 표시할 점의 양을 함께 고려합니다. 이동 중에는 탐색을 우선하고, 시점이 안정되면 상세 데이터를 보완합니다. 네트워크·디코딩·GPU 메모리 상황도 데이터 선택에 반영합니다.

기기 환경에 맞춰 탐색을 이어갑니다.

PC·스마트폰·태블릿에서 웹 브라우저로 같은 점군에 접근합니다. 화면 크기와 가용 자원에 맞춰 표시할 데이터의 양을 조절하고, 새 데이터가 준비되는 동안 기존 형상을 유지해 탐색을 이어갑니다.

표시된 점을 원본과 연결합니다.

원본 포인트 식별자를 유지해 선택·라벨 작업을 원본 데이터에 연결합니다. 라벨과 편집 상태는 원본 및 LOD 데이터와 분리해 관리하며, 탐색 결과를 후속 분석과 작업 도구로 이어갑니다.
