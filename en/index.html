OPTREE CORE

Optree Framework

Optree Framework is an Octree-based structure independently developed by Optimize3D for industrial point-cloud data. It progressively loads the required spatial regions and levels of detail, preserves links between lightweight data and source points, and lets ultra-scale field data and multiple tools share one project structure.

01Progressive LOD 02Source-index Mapping 03Shared Project Data 04Resource-aware Streaming

GEO-TOPOLOGY INTELLIGENCE

Optree Recognition Engine

An industrial engine that operationalizes ultra-scale point-cloud recognition for shipyards, engineering firms, and large manufacturing and construction sites. It computes and manages FPFH local geometric features and TDA topological features at the Optree-node level, then fuses them with deep-learning features to distinguish complex industrial objects.

OPTREE NODES Ultra-scale Point Cloud LOD · source index · feature cache
→
LOCAL GEOMETRY FPFH Normals · curvature · local relationships
GLOBAL TOPOLOGY TDA / PH Connectivity · loops · persistence
→
GEO-TOPOLOGY FUSION Industrial Recognition Classification · segmentation · similarity · outliers

PRACTICAL AT SCALE

Built for ultra-scale data

Only the required Optree nodes and levels of detail are processed, avoiding a full in-memory load. Feature caching and source-index mapping make training, review, and inference outputs practical to reuse.

OPEN INTEROPERABILITY

Connects with every major platform

The engine is not tied to a single viewer or training environment. Standard files, APIs, and project interfaces connect it with point-cloud, CAD and BIM, AI, digital-twin, and engineering platforms.

Representative applications

Examples of shipbuilding and manufacturing scan data connected to inspection, recognition, and automation data.

Deep-learning spatial recognition module for a container-ship cargo hold

Structures and workspaces are recognized from a shipyard cargo-hold point cloud, with object segmentation, spatial relationships, and inspection-reference data organized into an automation module.

3D point-cloud object detection in an LNGC cargo hold

Deep-learning point-cloud processing and post-processing were studied to detect and segment scaffolding systems during cargo-hold flatness measurement.

  • InputLNGC cargo-hold scan data
  • AnalysisObject detection, semantic segmentation, post-processing
  • OutputMeasurement-target organization and inspection support
2026

Ship-block support installation inspection

Supports are segmented and extracted from ship-block underside point clouds, then compared with the reference layout to quantify installation deviations.

  • Input3D LiDAR scans beneath a ship block
  • AnalysisPointVector segmentation, DBSCAN and RANSAC
  • OutputSupport position, height, and installation deviation
2025

Topology- and Geometry-Augmented Lightweight Shipyard Point-Cloud Datasets

Topologically significant structures and local geometric features were extracted from large-scale ship-block and shipyard point clouds to reduce data volume while preserving the shape information and performance required for deep-learning object detection.

  • InputLarge-scale ship-block and shipyard-environment 3D point clouds
  • AnalysisTDA persistent homology, FPFH geometric feature extraction and augmentation
  • OutputLightweight training datasets preserving shape quality and object-detection performance
2016-2021

3D scanning and shape-deviation analysis for small craft and FRP molds

Scan data from small craft and production molds were compared against reference shapes to verify dimensional control and process-improvement potential.

  • InputSmall-craft and FRP mold scan data
  • AnalysisRegistration, deviation map, quality criteria
  • OutputMold quality-control and improvement evidence
